# Quick deployment of NBS {{ site.version_latest }}

This section provides streamlined paths to deploy NBS 7 infrastructure and core microservices, one for each supported hosting environment. Each path is intended for experienced administrators familiar with your cloud provider, Kubernetes, Helm, and Terraform. For a detailed walkthrough with more explanation at each step, use [NBS 7 full deployment](full-deploy.html) instead. Both paths create the same infrastructure and services.

## In this section

Choose the path for your hosting environment:

- **[Quick deployment on AWS](quickstart/quickstart-aws.html)**: Deploy NBS 7 infrastructure and core microservices in an Amazon Web Services (AWS) environment.
- **[Quick deployment on Azure](quickstart/quickstart-azure.html)**: Deploy NBS 7 infrastructure and core microservices in a Microsoft Azure environment.
