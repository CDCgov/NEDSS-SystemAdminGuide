# Deploy NBS {{ site.version_latest }}

This section covers the {% include term-tooltip.html key="nbs-7" term="NBS 7" id="deploy-nbs-7" %} deployment process, from prerequisites and infrastructure setup through microservices deployment and go-live. You can follow either of two deployment paths. Both paths create all of the same infrastructure and services:

- **[NBS 7 quick deployment](deploy-nbs7/quickstart.html):** A condensed path with commands and minimal explanation. Intended for administrators who have deployed NBS 7 before or who do not need step-by-step guidance.
- **[NBS 7 full deployment](deploy-nbs7/full-deploy.html):** Complete instructions with an explanation at each step. Suggested for a first NBS 7 deployment, or any time you want the detailed walkthrough.

> The procedures in this section reflect NBS {{ site.version_latest }}. For earlier releases, see **Previous Versions** in the sidebar.
